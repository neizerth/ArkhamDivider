# Commits

Commits are authored only by the git user already configured for this repository.

- Do not add `Co-authored-by` for Claude, Cursor, or any other agent.
- Do not add `Made-with: Cursor` or other agent attribution trailers.
- Do not pass `--author`.
- Do not set `GIT_AUTHOR_NAME`, `GIT_AUTHOR_EMAIL`, `GIT_COMMITTER_NAME`, or `GIT_COMMITTER_EMAIL`.
- Do not change git config.

A human co-author trailer is allowed only when the user explicitly asks for that person.
